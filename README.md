# Jongman Lee

Personal website — background, publications, and projects.

The site is a single static page (`index.html`) with no build step.

## Editing

- **Profile links**: edit the `profileLinks` object near the bottom of `index.html`
  (Google Scholar, LinkedIn, email, and one extra link). Blank values are hidden.
- **Sections**: replace the placeholder text in the Background, Publications, and
  Projects sections. A publication entry format is in an HTML comment there.

## Publishing with GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → select the branch and `/ (root)`.
